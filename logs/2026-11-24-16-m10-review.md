## Learned / surprises
- 42% of the old worst-case bench was timer/serial events nothing could
  observe. No bench line runs a DMG-mode ROM.
- The size caps were dev-board (H753) constraints; on the H735 the whole
  core fits a 128 KiB ITCM. Per-function caps kept bending code even after
  the first reform.
- LLVM stops folding an address with >100 memory uses in one function
  (`-cgp-max-address-users-to-scan`); that was most of `Cpu::run`'s tick.
- Removing every `inline(never)` in apu/ made things worse (bus-facing
  entry points got inlined into the bus): attributes need measuring.
- SameBoy master copies value+1 blocks on an HDMA cancel with a pending
  block (as we did); the review's "neither reference" claim was wrong.
- Agents sharing one `flock` works, but a hung mutated test held it for
  20 minutes once, and one agent used a relative lock path.
