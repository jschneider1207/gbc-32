# Code-size budgets for gbc-core functions on the MCU build
# (thumbv7em-none-eabihf, release with `codegen-units = 1` as pinned in
# Cargo.toml, -C target-cpu=cortex-m7). Checked by scripts/check-code-size.sh;
# rules in docs/perf.md "Code-size budgets" (human, 2026-11-24).
#
# Two kinds of line; '#' lines and blank lines are ignored:
#   <bytes> <symbol>          gates: over budget, or symbol not found, fails.
#                             Only for functions in the ITCM set
#                             (perf/itcm-sections.txt); the script fails a
#                             gating line for a function outside it.
#   report <bytes> <symbol>   printed with its size, never fails. For
#                             functions that stay in flash (the script fails
#                             a `report` line for a function in the ITCM
#                             set), and for the special name `(total .text)`.
# <symbol> is the exact demangled name, as printed by nm -C.
#
# Gating lines:
#  - A symbol that is not found (renamed or inlined away) is a failure:
#    update this file, do not delete the line to make the check pass.
#  - Budgets are at most the measured size + 5% (rounded up). Raising one is
#    committed with the change that needs it, with the measured size and the
#    reason in the commit body. What binds in the end is the ITCM-set total
#    (scripts/check-itcm-set.sh); these keep one function from eating its
#    margin unseen.
#  - Every function in the ITCM set of 128 B or more has a line.
#
