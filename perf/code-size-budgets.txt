# Code size of gbc-core on the MCU build (thumbv7em-none-eabihf, release with
# `codegen-units = 1` as pinned in Cargo.toml, -C target-cpu=cortex-m7).
# Checked by scripts/check-code-size.sh; rules in docs/perf.md "Code-size
# budgets".
#
# Sized for the final MCU, the STM32H735IGK6 (human, 2026-11-24: the caps
# are the ones valid for the final MCU; the Stage 2 dev board may run
# slower). Its ITCM is configured to 128 KiB (RM0468 Rev 3 §2.4 Table 8,
# TCM_AXI_SHARED[1:0] = 01 in FLASH_OPTSR2_PRG, §4.9.25) and holds all of
# gbc-core, so no function needs a cap of its own.
#
# Two kinds of line; '#' lines and blank lines are ignored:
#   <bytes> (total .text)     THE GATE: the sum of every .text* section in
#                             the rlib, alignment padding included, before
#                             the linker drops what a front end does not
#                             use. Over it fails. Exactly one such line.
#   report <bytes> <symbol>   printed with its size, the figure and % of
#                             it; never fails. Above the figure it prints
#                             "over, report only"; a symbol that is not
#                             found prints a WARN (update the line).
#                             Every per-function line is a report line.
# <symbol> is the exact demangled name, as printed by nm -C.
#
# Gate: 128 KiB ITCM (131,072 B) minus an 8 KiB platform reserve (ISRs,
# the frame blit, compiler_builtins, veneers) = 122,880 B. Provisional
# until the H735 firmware crate exists and its linked ELF is measured
# (LTO changes inlining). Raising it needs the human.
122880 (total .text)
#
# Per-function sizes (report only). The figures are the caps these lines had
# while they gated (measured + 5%; the last ones stopped gating 2026-11-24),
# kept so that growth shows up in review. Lower a figure when a function
# shrinks for good; do not raise one to hide growth.
#
