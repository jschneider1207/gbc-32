# ITCM-resident gbc-core functions: one linker input-section glob per line,
# `<glob>  # <demangled name>`; '#' starts a comment. Single source of truth
# for the front ends' `.itcm` linker rules (docs/perf.md "ITCM placement
# plan (M8)", ADR 0026) and for scripts/check-itcm-set.sh.
#
# The globs match the length-prefixed path segments of rustc's v0-mangled
# section names, never the crate hash (it changes with the compiler/build).
# `*` has the same meaning in the shell's `[[ == ]]` as in GNU ld / lld.
# Measured on the release build with `codegen-units = 1` (Cargo.toml), where
# `Ppu::vram_blocked`, `Ppu::oam_blocked` and `render::frame_row` are inlined
# into their callers and so have no section.
#
# ITCM_BUDGET_BYTES: the budget for the summed size of every section matched
# below. Assumption (docs/perf.md): H753 ITCM 64 KiB minus an 8 KiB front-end
# reserve (ISRs, blit, compiler_builtins, veneers) = 56 KiB.
ITCM_BUDGET_BYTES=57344
#
